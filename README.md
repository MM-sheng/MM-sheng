# MM-sheng

I build small, local-first AI tools and browser-based prototypes.

## Featured project

[Prompt Lens](https://github.com/MM-sheng/prompt-lens) is a local-first prompt debugger that scores, rewrites, and risk-checks AI prompts before they are sent to a model.

- Runs fully in the browser
- No backend, login, tracking, or API calls
- Includes scoring profiles for general, coding, writing, and research prompts
- Live demo: https://mm-sheng.github.io/prompt-lens/
