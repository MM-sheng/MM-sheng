I build AI tools and experiments that make model behavior easier to inspect and understand.

我做 AI 工具与实验，关注模型如何做决策、提示词如何改进，以及调用工具前如何检查风险。

## Start here

### [JevSpeak](https://github.com/MM-sheng/jevspeak) — a decision model that speaks

Can a model that cannot generate text still hold a conversation? JevSpeak turns probabilistic decisions into English or Chinese through a deterministic language compiler. You can inspect the decisions behind each reply.

**[Try the app](https://jevspeak.org)** · [Explore the code](https://github.com/MM-sheng/jevspeak)

### [404.directory](https://github.com/MM-sheng/404-directory) — risk checks before Agent actions

An experimental service that gives AI Agents an evidence-backed `allow`, `review`, or `block` decision before they use a third-party tool. Includes a prediction-market preflight workflow.

**[Connect an Agent](https://404.directory/connect?source=github)** · [Read the setup guide](https://github.com/MM-sheng/404-directory)

### [Prompt Lens](https://github.com/MM-sheng/prompt-lens) — inspect a prompt before sending it

A browser-based, rule-based prompt debugger. It checks structure, flags potential risks, and adds missing sections without sending your draft to a server.

**[Try it in your browser](https://mm-sheng.github.io/prompt-lens/)** · [Explore the code](https://github.com/MM-sheng/prompt-lens)
